# FurimaPostCalc
## メルカリ・フリマ専用：送料・梱包サイズ判定ツール

商品の梱包後サイズと重量を入力するだけで、利用可能な配送方法を比較し、**必須専用資材を含めた実質総額**の安い順に表示するブラウザツールです。

外部ライブラリ・外部APIに依存せず、ブラウザだけで動作します。

---

> **送料・専用資材費・サイズ・重量などの配送条件は、予告なく改定される場合や、購入店舗（コンビニ・郵便局・100均等）によって実際の金額と異なる場合があります。**
>

>
> **発送および専用資材の購入前に、必ず各配送会社・メルカリ等の公式情報や店頭の最新表示をご確認ください。**

**料金・規格データ最終確認：2026年9月15日（改訂版仕様：2026年9月16日）**

特にポスト投函型サービスは、梱包後の膨らみや実際の郵便ポスト投函口などによって利用できない場合があります。

## ✨ 主な機能

- 📦 **縦・横・厚さ・重量から配送方法を自動判定**（向き不問：3辺を自動回転して最適判定）
- 💰 **必須専用資材を含めた実質総額を比較**（最安配送方法を自動ハイライト）
- ⚠️ **送料・資材費の確認喚起と目安注釈**（店舗差・改定リスクの常時明示）
- 🔒 **「匿名配送のみ（メルカリ便限定）」絞り込みフィルター**＆識別バッジ
- 📐 **ネコポス等の最小サイズ（長辺23cm・短辺11.5cm）判定**
- 📮 **ポスト投函口に応じた段階的警告**（3.5cm超の注意喚起、4cm超除外など）
- ⚠️ **サイズ・厚さ上限付近の警戒表示**（残り0.2cm未満でhard警告、0.5cm未満でsoft警告）
- 🔗 **URLパラメータによる条件共有**（`?h=...&w=...&d=...&weight=...&notrack=0&anon=1`）
- 💾 **LocalStorageによる入力値・設定保持**
- 🌙 **ダークモード対応**
- ⌨️ **キーボード操作対応**
- 📱 **スマートフォン・レスポンシブ対応**
- 🌐 **外部通信・サーバー不要（完全オフライン動作）**

# 🔄 3辺の向き自動最適化（自動回転判定）

ユーザーが入力する「縦・横・厚さ」の順番に左右されず、ツール内部で数値を自動ソートして幾何学的に判定します。

- 例：`縦 30cm / 横 3cm / 厚さ 20cm` と入力しても、荷物を傾けた状態（`30cm × 20cm × 厚さ3cm`）として自動認識され、ネコポス等の厚さ3cm制限サービスが正しく「利用可能」と判定されます。

# 🔒 匿名配送（メルカリ便）フィルター

フリマ取引でプライバシーを重視するユーザーのために、**「匿名配送のみ表示（メルカリ便限定）」**トグルを搭載しています。

- **ON**: 住所・氏名を開示せずに取引できる「らくらくメルカリ便」「ゆうゆうメルカリ便」のみを表示
- **OFF**: クリックポストやスマートレター、レターパック等も含めた全配送方法を比較表示

各結果カードにも `[🔒 匿名配送]` または `[✉️ 宛名記入必要]` のバッジを表示します。

# 💰 「実質総額」について

本ツールでいう実質総額は、

```text
実質総額 = 基本送料 + 必須専用資材代（目安）
```

です。例えば、

```text
宅急便コンパクト: 450円 + 専用BOX70円 = 520円
ゆうパケットプラス: 455円 + 専用箱65円 = 520円
ゆうパケットポストmini: 160円 + 専用封筒20円 = 180円
```

となり、送料だけでなく専用資材を含めた真の最安が分かります。

> **※ご注意**：専用資材の価格は標準的な価格を基準としています。購入場所（郵便局・コンビニ・100円ショップ等）やまとめ買い枚数、将来の価格改定によって実際の購入額が異なる場合があります。任意資材（段ボールや緩衝材等）は自動加算せず、推奨資材として別枠表示します。

# ⚠️ サイズぎりぎりの場合と投函口基準

### 境界警告
- 厚さ（最短辺）上限まで **0.2cm未満**：`hard` 警告（膨らみで返送リスク高）
- 厚さ（最短辺）上限まで **0.5cm未満**：`soft` 警告（テープや衣類の膨らみに注意）
- 3辺合計上限まで **1.0cm未満**：`soft` 警告

### ゆうパケットポスト（シール式）の投函口基準
郵便ポストの投函口サイズ（従来型約3cm、新型約4cm）を考慮し、段階的に判定します：
- **3.0cm以下**：警告なし（安全に投函可能）
- **3.0cm超〜3.5cm以下**：`soft` 警告（新型ポスト等での投函を推奨）
- **3.5cm超〜4.0cm以下**：`hard` 警告（新型ポスト投函口約4cmにギリギリ、無理な投函注意）
- **4.0cm超**：判定除外（ポストに入らないため利用不可）

# ❓ FAQ

### Q. 一番安い配送方法を自動で選んでくれますか？
利用条件を満たす配送方法を実質総額の安い順に自動ソートし、最安のものをハイライト表示します。

### Q. 表示されている送料や資材代と、実際の金額が違うことはありますか？
**あります。** 配送会社の料金改定やキャンペーン、専用資材の購入店舗（郵便局・各コンビニ・100円ショップ・営業所等）の違い、まとめ買い時のセット単価の違いなどにより、実際の支払額と異なる場合があります。また、受付窓口での採寸結果が優先されます。**発送・資材購入前には必ず公式情報および店頭表示をご確認ください。**

### Q. 「縦・横・厚さ」はどの向きで入力すればいいですか？
どの向きで入力しても構いません。ツールが自動的に一番薄い辺を「厚さ」として判定するため、向きによる誤判定を防ぎます。

### Q. 匿名配送（メルカリ便）だけに絞り込めますか？
はい。「匿名配送のみ表示」にチェックを入れると、らくらくメルカリ便・ゆうゆうメルカリ便のみを抽出できます。

### Q. ネコポスはA4サイズですか？
メルカリの公式規格に準拠し、三辺合計60cm以内、長辺34cm以内、最小23×11.5cm、厚さ3cm以内、1kg以内として厳密に判定します。
